# Codex prompt - Scanner PWA improvement

Hãy nâng cấp scanner PWA với mục tiêu chạy tốt trên PDA Android:

- Input scan luôn focus.
- `inputMode="none"` khi bật chặn bàn phím ảo.
- Queue offline không mất dữ liệu.
- Sync retry rõ ràng.
- UI một tay, nút lớn, chữ rõ.
- Không thêm bước thừa trước khi scan.

Không làm thay đổi RPC sync nếu không cần.
